# RiskBounds

Analysis source, locked specification and aggregate results for **Early Student Withdrawal Prediction under Uncertain Event Timing: A Temporal Evaluation Study**, by Harish Kumar Mittal. This repository accompanies a manuscript; it is not evidence of journal acceptance or a deployed student-support system.

## What the study evaluates

The analysis uses OULAD's 2013J presentation to fit two fixed logistic predictors and separate source-only sigmoid calibrators, then evaluates 2014J records from six shared modules. Predictors use information through day 28; the recorded-withdrawal horizon is days 29–56. Students appearing anywhere in 2013J are excluded from the target before eligibility restrictions.

There are 6,771 known eligible target records and 58 records whose missing withdrawal dates leave eligibility and horizon outcomes uncertain. The primary result bounds calibrated registration-only Brier loss minus calibrated registration-plus-activity Brier loss over three admissible states per uncertain record. The interval is approximately **[0.0003071290, 0.0015331614]**, conditional on the fixed predictions, accepted labels and unrestricted Cartesian feasible set. These are finite-cohort identification bounds, **not confidence intervals**. The small activity gain does not establish fitting stability, transportability, intervention benefit or causal educational effects. Source sigmoid calibration did not improve target Brier loss.

## Contents and privacy boundary

| Directory | Contents |
|---|---|
| `analysis/` | Byte-preserved locked cohort, feature, bound and model source; protocol; synthetic/mock tests; source-data fingerprints. |
| `results/` | Aggregate complete-case metrics and exact bound fractions from the recorded run. |
| `figures/inputs/` | Twelve aggregate tables: eight plotting inputs and four supporting scientific-reporting exhibits. Curve coordinates contain no probability thresholds or student identifiers. |
| `figures/scripts/` | Presentation-only figure regeneration from those aggregates. |
| `tools/verify_package.py` | Standard-library static manifest and syntax verification; no model or data execution. |

Raw student records, individual identifiers or split membership, feature matrices, individual predictions, fitted models, original authorization receipts, private logs, manuscript drafts and source-paper downloads are intentionally absent. Tests use explicitly synthetic keys. Field names such as `id_student` in source code describe the public schema, not disclosed identifier values. Aggregate small-cell counts are descriptive and should not be used to identify individuals.

## Verify the supplied package without fitting

From this repository's root:

```sh
python tools/verify_package.py
```

This checks every allowlisted byte against `MANIFEST.json`, the historical protocol/code fingerprints, Python syntax and aggregate CSV schemas. It rejects unsafe paths, symlinks and extra files in clean publication staging (Git metadata is excluded). Generated local figures, caches and downloaded data are not allowlisted, so run this check on a clean package before generating them. A passing hash/schema check does not replace human privacy review. It does not import or execute the analysis modules, download data or train models.

## Regenerate presentation figures only

Use Python 3.12 with the versions in `figures/requirements-figures.txt` and the DejaVu Sans font distributed with Matplotlib:

```sh
python -m pip install -r figures/requirements-figures.txt
python figures/scripts/build_manuscript_figures.py
```

This produces seven PDF/SVG/PNG figures from the existing aggregates, plus a local output manifest. It does not fit models, reconstruct student records or create statistical uncertainty estimates. The source implements the accepted figure layout; final manuscript captions are maintained in the manuscript, not generated by this script.

## Obtain data and inspect the historical analysis

Download the original dataset separately from [UCI OULAD](https://archive.ics.uci.edu/dataset/349/open+university+learning+analytics+dataset), DOI [10.24432/C5KK69](https://doi.org/10.24432/C5KK69). The inspected release is CC BY 4.0. Preserve its attribution. The expected ZIP is 46,748,244 bytes with SHA-256 `f2ed1902616c1fe8d2824d872c0b7d2d72be435bf0124d077044fe4be2c6d3e4`; table fingerprints are in `analysis/audit/data_manifest.json`. Do not substitute a reformatted copy silently.

The preserved acquisition utility can download and safely extract the official archive when network access is available:

```sh
cd analysis
python acquire_oulad.py
```

**No new fit was performed while preparing this repository.** See [ANALYSIS.md](ANALYSIS.md) before running any further analysis. The original runner is intentionally hash- and authorization-gated; an ordinary invocation is a non-fitting dry run. The historical receipt is not distributed or repurposed as permission for another run. A separate, mock-tested local opt-in adapter is supplied; it has not been executed on OULAD. Do not claim an independent historical rerun merely because source and aggregates are available.
